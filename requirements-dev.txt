# A second, independent GDS reader. `tools/oracle.py` builds the answer key with
# gdstk and a plain XML parse of the .lyp, importing nothing from analyzer/, so a
# passing grade in tools/judge.py means the answer agrees with a separately written
# program rather than with the analyzer's own output. Choosing KLayout here would
# have made the key confirm the analyzer's mistakes. Nothing in app.py imports it.
